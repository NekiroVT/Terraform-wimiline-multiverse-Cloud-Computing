## 2. Limitaciones Operacionales del Entorno Educativo

1. **IAM en AWS Academy:** Las políticas de laboratorio impiden la creación de roles personalizados (`iam:CreateRole`) o proveedores de identidad OIDC (`iam:CreateOpenIDConnectProvider`), motivo por el cual no se pudo implementar una federación de identidades directa entre Azure y AWS.
2. **SSM Parameter Store:** Al compartir el `LabRole` entre las instancias, el aislamiento a nivel de proceso en la lectura de parámetros depende de la aplicación y no de permisos IAM granulares individuales por recurso.
3. **Vigencia del Token SAS:** La SAS que autoriza la sincronización hacia Azure expira el **19/12/2026 a las 19:00 hora de Lima (20/12/2026 00:00 UTC)** y debe renovarse antes de dicha fecha para mantener la continuidad del respaldo.
